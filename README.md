# Análise de Cotação do Bitcoin (BTC/BRL)

Programa desenvolvido em Python para consultar uma API e gerar um relatório da cotação do Bitcoin em relação ao real brasileiro (BRL).

O sistema apresenta o preço atual, os valores máximo e mínimo e as variações em reais e em porcentagem, utilizando dados obtidos por meio da AwesomeAPI.

### Tecnologias utilizadas

- Python
- Requests
- AwesomeAPI (cotação BTC/BRL)

### Como executar

1. Abra o arquivo `main.py` no VS Code.
2. Clique com o botão direito no editor.
3. Selecione **Run Python File in Terminal** para executar o programa.

O sistema consultará a API e exibirá o relatório no terminal.

**Observação:** para executar o programa, é necessário ter o Python instalado e a biblioteca `requests` disponível no ambiente.
