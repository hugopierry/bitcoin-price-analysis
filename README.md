# Análise de Cotação do Bitcoin (BTC/BRL)

Programa desenvolvido em Python para consultar uma API e gerar um relatório simples da cotação do Bitcoin em relação ao real brasileiro (BRL).

O sistema apresenta o preço atual do Bitcoin, a máxima, a mínima e as variações em reais e em porcentagem, utilizando dados obtidos por meio da API.

### Tecnologias utilizadas
- Python
- Requests
- AwesomeAPI (cotação BTC/BRL)

Este projeto faz parte dos meus estudos sobre consumo de APIs e manipulação de dados com Python.
